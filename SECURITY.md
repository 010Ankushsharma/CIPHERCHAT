# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x.x | ✅ |
| < 1.0 | ❌ |

## Reporting a Vulnerability

CipherChat takes security seriously. If you discover a security vulnerability, **please do not open a public GitHub issue.**

### Responsible Disclosure

Email: security@cipherchat.app  
PGP key: https://cipherchat.app/.well-known/security.txt

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

### What to Expect

- Acknowledgement within 48 hours
- Status update within 7 days
- Fix timeline communicated within 14 days
- Credit in release notes (if desired)

### Scope

**In scope:**
- Signal Protocol implementation issues
- Authentication/session management flaws
- Key storage vulnerabilities
- Server-side data exposure
- Cryptographic weaknesses

**Out of scope:**
- Rate limiting bypass without demonstrated impact
- Social engineering attacks
- Physical device access scenarios
- Third-party service vulnerabilities

### Bug Bounty

We do not currently operate a paid bug bounty program. We do offer public acknowledgement and our sincere gratitude for responsible disclosures.
